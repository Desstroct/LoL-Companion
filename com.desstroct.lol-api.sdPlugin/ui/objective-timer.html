How it works

Tracks Dragon, Baron, and Rift Herald respawn timers in real-time.

Key: Shows the most urgent objective countdown.
Dial: Rotate to cycle between Dragon / Baron / Herald views.

Dragon: 5 min respawn (Elder: 6 min). First spawn at 5:00.
Baron: 6 min respawn. Spawns at 20:00.
Herald: 4 min respawn. Spawns at 14:00 (max 2 heralds).

Uses the Live Client Data API game events — fully Riot ToS compliant.
